# Data-access probe for steps 2–3 (Colombia)

Probed on 2026-10-03 from the project server, with no credentials unless
stated. "Remote window" means a Colombia subset can be read over HTTP range
requests (GDAL `/vsicurl/`, `/vsizip//vsicurl/`) without downloading the global
file. "Login: yes, available" means the source needs an account that Anne
already has (NASA Earthdata or CDSE). Access was tested with netrc-based curl
range requests; no credential contents were read or printed. Licences marked
"(not re-verified)" are taken from the provider page or the task brief and were
not checked against a licence file during this probe.

Step 1 inputs (the authors' Zenodo record 10.5281/zenodo.7428804 and GADM 4.1)
are downloaded by `notebooks/01_data_download.py` and are not repeated here.

## Summary

- **Everything needed for the ten-variable final model is reachable without new
  accounts:** Fagan labels (remote GPKG), Hansen GFC, ESA CCI LC (CEDA,
  no CDS account), SoilGrids v2017 OCDENS/PHIHOX, WorldClim 2.1, and RESOLVE
  biomes.
- **Step-3 extras:** NPP (NTSG, no login) is fine. Burned area: GlobFire downloaded in full
  in the full run after many PANGAEA 503 retries (slow, unreliable host; MCD64A1 via Earthdata as fallback). Road density (GRIP4)
  is fine. Slope works via Earthdata, or with no login via NASADEM or Copernicus
  DEM. WDPA 2020 needs a request to UNEP-WCMC. Distance to water (Kummu 2011)
  is not distributed.
- **Re-derivation needed:** bioclim PCA loadings (only variance is published);
  tree cover 2018 construction; land-cover simplification (31 → 11 classes).
